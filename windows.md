# Additional Windows 11 Installation Instructions

* Install WSL from Microsoft store or Powershell terminal (open as administrator): 
On powershell it's one command: "wsl --install" then restart the PC.

* Install Docker desktop for Windows: https://www.docker.com/products/docker-desktop/

* Make sure wsl2 integration is enabled in the Docker app settings by navigating to settings -> general -> Use WSL 2 based engine): https://docs.docker.com/desktop/features/wsl/#turn-on-docker-desktop-wsl-2

* Open wsl terminal by writing "wsl" in powershell. Also make sure Docker desktop app is running in the background on Windows.

* On WSl terminal follow the steps to clone and install the course docker environment just as you would using Ubuntu.
